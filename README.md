# Automation Assessment

This repository contains UI and API automation test solutions.

## UI Automation (SauceDemo)
https://www.saucedemo.com/

Covered Scenarios:
- Q1: Locked out user login validation
- Q2: Standard user checkout and order flow
- Q3: Performance glitch user checkout flow

---

## API Automation (ReqRes API)
https://reqres.in/api

Covered Scenarios:
- Login API (token generation)
- GET user validation
- PUT update user profile
- PATCH single field update
- Negative test cases (4xx validation)

---

## Tools Used
- Java
- Selenium WebDriver
- Postman

## Execution
- UI tests can be executed via Java class files
- API tests can be run using Postman collection
